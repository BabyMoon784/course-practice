## 怎么练

- **顺序练习**　按原题顺序往下做。想复习刚学完的一节，可以在「练习范围」里选它的小节编号。
- **随机练习**　选好范围后，系统会打乱题序。同一轮里每道题只出现一次。
- **错题重练**　答错的题会自动收进这里。下次答对，这道题就会从错题本移出。

选好选项后，点「提交答案」就能看到判分。多选题需要选中全部正确选项，多选或漏选都会判错。

> **下次接着练**  
> 用同一台设备、同一个浏览器打开刷题本，就能接着上次的位置练习。手机和电脑各自保存记录，清除本站的浏览器数据也会清除进度和错题。
